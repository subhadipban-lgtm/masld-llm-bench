MASLD-LLM: the complete plan

One program, two arms. The benchmark arm (Cell-submission core): MASLD-Bench corpora → baselines → frontier bracket → compact tuned models → paper. The drug-discovery arm: KG-nominated targets → AlphaFold/Chai structural layer → natural-product screening → validated computational nomination. Both arms share the KG, the frozen test discipline, and the MASLD-LLM models.

The unified sequence — workstreams W1–W5

Five parallel workstreams with explicit dependencies. W1–W3 are the benchmark arm; W4 is the drug arm; W5 (paper) consumes both. Each phase ends at a git commit + frozen artifact.

W1Corpora & data completionlaptop · weeks 1–3
Freeze-3 (this week): parse the 5 series-matrix files + GSE162694/GSE247407 counts → harmonise (probe→gene collapse, per-sample standardisation) → add ~330 staged train samples → rebuild MB-10xx with the external cohorts included. Then freeze-4: GSE48325 DNAm → age/fibrosis-from-methylation tasks (MB-30xx). Then ArrayExpress tier-1 (E-MTAB-9815 + 6 PHH perturbation panels → MB-91xx human-relevant side), and the MB-95xx patient-profile→compound tasks once W4 produces affinities. Includes: Fujiwara KU internal-test build; MB-7002 masked-gene variant; exemplar supplement (S8) formalisation.
Gate: >400 staged train samples total; every corpus has a checksummed manifest entry; DNAm tasks pass the ML-baseline sanity check.
W2Baselines & frontier bracketlaptop + API · weeks 2–4
First (before any LLM): ML fibrosis clocks (ElasticNet/HGB) + clinical scores (FIB-4/NFS-style from prompt features) on the frozen test → results/baselines.json. This is the anchor every LLM number gets compared against. Then the OpenRouter frontier bracket (≥16 models, zero-shot greedy, 300–500 prompts/task stratified) → results/frontier_runs/. Freeze the analysis plan (model list, ranking scheme, primary contrasts) before the first API call.
Gate: baselines beat chance on every task; frontier bracket complete for the current task set; analysis plan committed and dated.
W3Model ladder (Colab)Colab Pro → Pro+ · weeks 3–10
Stage-A pretraining corpus (KG text + drug facts) → 0.6B LoRA smoke test on L4 (minutes) → 1.7B (Pro) → evaluate both against baselines + frontier → only then Pro+ month for the 9B two-stage QLoRA (A: 1 epoch lr 2e-5; B: 3 epochs lr 1e-4, hierarchical-uniform sampled mixture ~60k prompts) → merge → vLLM single-pass eval on the identical frozen prompts → ablation grid (stage A on/off, sampling shares, named/masked, traces).
Gate (paper-critical): 1.7B within CI of frontier on ≥1 domain before spending 9B CU; 9B separated CI on the C2 contrast, or pivot claim weight to C3/C4.
W4Drug-discovery armlaptop + Colab · weeks 2–12 (parallel)
NP library: COCONUT pull → RDKit filters (MW 250–600, LogP ≤5, PAINS/aggregator removal) → ~50–150k candidates → 3D conformers. Structural layer: extend AlphaFold batch to the top-20 KG-nominated personalization targets. Screening: start Vina 5k compounds × 5 targets (reproducible, cheap) → Chai-1 co-folding on the top ~10k pairs (Pro+ A100, 10–20 CU). Validation: resmetirom↔THRβ and pioglitazone↔PPARα must rank in the top percentiles — this calibrates the whole pipeline. Output: MB-95xx tasks (patient profile → compound reasoning) + top-20 NP hand-off list for the lab.
Gate: positive controls rank high (top 5% of library); if not, fix filters/scoring before any NP claim. No efficacy language anywhere.
W5Paper & releaseweeks 12–24
Figures F1–F6 per the Cell plan (F5 gains the drug-arm panel if W4 gates pass); STAR Methods; supplements S1–S10; MASLD-Claw demo over masld_kg_v5 + the compound layer; HF dataset + model release at preprint time; leaderboard GitHub page. Journal ladder: Cell → Cell Metabolism → Cell Reports Medicine.
Gate: internal review + co-author CRediT sign-off; all figures regenerate from committed code.

04

Rules that hold across the whole program

  • The frozen test is sacred. EPos + Gubra, 13,273 prompts, locked 2026-09-29. Any builder change bumps the manifest and invalidates eval runs — by design.
  • Features from train only; pairwise intra-cohort; label-free per-sample standardisation. Recorded per corpus in the manifest.
  • Analysis plan freezes before the frontier bracket runs — no post-hoc model cherry-picking.
  • Drug arm speaks nomination, not efficacy. Positive-control calibration first; PAINS-filtered; no therapeutic claims.
  • Everything commits to git at phase boundaries; every artifact carries provenance (checksums, versions, seeds).
  • Laptop-first: nothing goes to Colab that runs locally in <10 minutes.
